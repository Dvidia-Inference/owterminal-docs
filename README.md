# OpenWeights Terminal docs

[OpenWeights Terminal](https://owterminal.com) connects open-weights models with the machines that run them. Compare models on real hardware, call one through an OpenAI-style API, or put your own machine to work and keep 80% of each paid job it finishes. It is a product of [DVIDIA](https://dvidia.org).

This repository holds the public docs. It is a mirror: a script copies one folder from the `main` branch of the private product repository, so edits made here are overwritten. Issues and corrections are welcome.
